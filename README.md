# wjlmanagement.com

Static site for WJL Management. Plain HTML and one stylesheet, no build step.
Rebuilt 2026-10-13 from the Squarespace site, keeping its copy and look.

- `/` home, `/contact-us/` contact, `/privacy/` privacy policy and `/terms/` terms of service (both also cover the Claude Email
  Connector OAuth app), `404.html`.
- `/about` and `/home` redirect to `/` because the old Squarespace site linked to them.
- Fonts: Cormorant Garamond (stand-in for Squarespace's Adobe-licensed Orpheus Pro) and Inter Tight,
  both from Google Fonts.

Hosted on GitHub Pages; DNS stays at Squarespace Domains.
