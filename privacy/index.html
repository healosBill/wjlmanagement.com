Claude Email Connector

Claude Email Connector is a private tool operated by Bill Liatsis of WJL Management for his own use. It is not offered to the public. It lets his AI assistant, Claude by Anthropic, read and manage email in Gmail accounts that he owns.

  • What it accesses. When an account owner connects a Gmail account, the tool requests Gmail’s “modify” permission. It uses that permission to search, read, label, archive, trash and draft messages, and to send or reply to email, only when the account owner asks it to.
  • Where data is stored. Google authorization tokens are stored only on the account owner’s own computer, in a file readable only by that user. Email content is not stored by the tool. It is fetched from Gmail when requested and passed to Claude to answer the owner’s request.
  • Sharing. Email content requested by the owner is sent to Anthropic, which provides Claude, to fulfil that request. No data is sold, used for advertising, or shared with anyone else.
  • Google API data. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Revoking access. Access can be revoked at any time at myaccount.google.com/permissions. Revoking access makes the stored token useless immediately.
